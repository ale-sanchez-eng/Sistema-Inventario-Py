# Sistema de Inventario en Python

Sistema de inventario desarrollado en Python utilizando Programación Orientada a Objetos (POO) y SQLite para el almacenamiento permanente de los datos.

## Sus funciones

- Agregar productos.
- Listar productos.
- Buscar productos por nombre o categoría.
- Modificar productos.
- Eliminar productos.
- Registrar entradas de stock.
- Registrar salidas de stock.
- Detectar productos con stock bajo.
- Consultar historial de movimientos.
- Guardar los datos utilizando SQLite.

## Tecnología y herramientas utilizadas

- Python 
- SQLite
- Programación Orientada a Objetos (POO)
